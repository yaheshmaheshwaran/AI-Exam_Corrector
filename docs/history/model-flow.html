Marklume Model Flow

Which AI model Marklume asks, in what order, for each preset with Gemini off and on. Read each row left to right: the first model is asked first, and the next one only if it fails (offline, out of quota, refused, or keeps erroring). Ollama, in amber, is the model on your Mac.

Reading jobs

Copy what is on the page: page layout, a second reading of unclear handwriting, equations, syllabus import. TrOCR on your Mac reads all handwriting first; a model is asked only for what TrOCR is unsure of.

Judgement jobs

Decide what counts: reading the question paper, diagrams, the AI answer key, matching your own key, and marking.

Backup marker

Only with Gemini on. When every Gemini marking model is out of quota, it marks whole scripts instead, and every mark is flagged for your review.

One marker per script

The first model that answers a marking request marks that whole script. If it fails halfway, the script stops or waits; it does not switch to the next model mid-script.

Gemini off means nothing goes to Google

Even with a key saved. With Gemini on but no key, marking fails instead of falling to the open model.

Ollama must be open to help

Ollama is only a fallback if the Ollama app is running with qwen3-vl:8b-instruct pulled. If it is not, the error you see names Ollama, even when the real problem was Kaggle or Hugging Face.
